Todo Application

Project Description
This project is a Todo Application built with React. It demonstrates frontend engineering skills including routing, pagination, search, filtering, error handling, and responsive design.

Users can:
View todos
Add todos
Edit todos
Delete todos
Search todos
Filter todos
View todo details
Navigate between pages

The application was built as part of the AltSchool Frontend Engineering Second Semester Examination.

Features
Todo List
Displays a list of todos
Shows title, details and completion status
Pagination with 10 todos per page
Responsive layout

Todo Details
Separate page for each todo
Shows full todo information
Edit todo details
Navigate back to main list
Search and Filtering

Users can:
Search todos by title or details

Filter todos by:
All tasks
Completed tasks
Incomplete tasks

CRUD Operations
The application supports:
Create: Add new tasks
Read: View tasks, View task details
Update: Edit existing tasks
Delete: Remove tasks with confirmation

Error Handling
The application includes:
Error Boundary component
Cusom error test page
Custom 404 page
Accessibility

The application uses:
Semantic HTML
Accessible form inputs
ARIA labels
Keyboard-friendly buttons

Technology Stack
Core Technologies
React: Used for building the user interface.
React Router: Used for navigation and routing.
Vite: Used as the development environment.
Tailwind CSS: Used for styling and responsive design.
